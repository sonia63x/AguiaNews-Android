# 🦅ÁguiaNews V19 — Android APK

Projeto Android nativo com WebView para empacotar o ÁguiaNews V19 como aplicativo.

## Build automático no GitHub Actions

1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Abra a aba **Actions**.
4. Execute **Build ÁguiaNews APK**.
5. Quando terminar, abra a execução e baixe o artefato **AguiaNews-debug-apk**.

O APK gerado é de debug e pode ser instalado diretamente no Android para testes.

## Build local

Abra a pasta no Android Studio e sincronize o projeto. O projeto usa Android Gradle Plugin 9.4.0, Gradle 9.6.0 e AndroidX WebKit 1.17.0.
